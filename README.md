# kgo-droid.github.io

Personal site of **Keigo Adachi (足立圭悟)**, aka Kei / Kgo: web developer & backend programmer.

Live at **https://kgo-droid.github.io**

Inspired by Miyajima:

- floating torii in the sea, five-storey pagoda on the hill, stone lantern on the beach
- day / night toggle (sun ↔ moon); remembers your choice
- koto-style music generated live with the Web Audio API (speaker button)
- deer that wander the beach: tap one and it bows, tap the sand to drop a shika senbei and one walks over to eat it
- fish jump out of the sea (tap the water), momiji leaves fall, birds by day, shooting stars by night
- the **work** window pulls my public repos from the GitHub API

Plain HTML, CSS and JavaScript, no build step: `index.html`, `style.css`, `script.js`.
